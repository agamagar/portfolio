Brick Jali — one cuboid, five bonds

A single brick primitive (4 : 2 : 1 — length : width : height) is rotated and repeated to build five traditional jali/bond patterns, matching the reference plate: diamond trellis, herringbone, basket weave, diagonal coursing, and a tilted perforated screen. Drag any panel to orbit it.

All five, one rule set: every brick is the same size and the same orientation, laid in one uniform running bond with zero gap — each brick's edge shared exactly with its neighbour's. No rotation, no spacing, no missing brick anywhere. The pattern is only depth — individual bricks pushed forward or pulled back along the wall's thickness — and the raking key light is what turns that depth map into a diamond, a chevron, a weave. Drag a panel toward front-on (camera flat) and the pattern flattens with it, because underneath the light it was always just a perfectly gapless wall.
